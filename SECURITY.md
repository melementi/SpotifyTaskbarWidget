# Security policy

## Supported versions

Only the [latest release](https://github.com/melementi/SpotifyTaskbarWidget/releases/latest) gets fixes.

## Reporting a problem

Please do not open a public issue for a security problem. Report it privately instead: open the repository's **Security** tab and choose **Report a vulnerability**.

What the widget sends over the network and stores on your PC is described in [SECURITY_AND_PRIVACY_AUDIT.md](SECURITY_AND_PRIVACY_AUDIT.md).
